JESD204 Component-Level Testbenches

Overview

The component-level testbenches verify individual JESD204 IP modules in isolation. They are located in the HDL repository at library/jesd204/tb.

These testbenches complement the system-level testbenches (like JESD loopback) by testing specific functionality at a granular level and supporting multiple simulators.

Supported Simulators

The simulator can be selected through the SIMULATOR environment variable:

$SIMULATOR

Simulator

modelsim

Mentor/Siemens ModelSim/QuestaSim

xsim

AMD Xilinx Vivado Simulator

xcelium

Cadence Xcelium

(default)

Icarus Verilog (iverilog)

Building and Running

  1. Open a Cygwin or bash terminal

  2. Navigate to the testbench folder:

    cd library/jesd204/tb

  3. (Optional) Set the simulator:

    export SIMULATOR=xsim

  4. Run a testbench:

    ./loopback_tb

Output files:

  • VCD waveforms: vcd/<testbench_name>.vcd

  • Simulation logs: <testbench_name>_<simulator>.log
