FIELD
[19] 0x0
UNKOWN_INSTRUCTION_ERROR
RO-V
Unknown slave instruction. Cleared by ``HSCI_MASTER_CLEAR_ERRORS``.
ENDFIELD

FIELD
[27:20] 0x00
SLAVE_ERROR_CODE
RO-V
Last slave error frame:

* [0] - unknown instruction received.
* [1] - bad parity detected.
* [2] - address size error (more than 4 address sub-frames received).
* [3] - byte number size error (more than 4 byte number sub-frames
  received).
* [4] - write FIFO full.
* [5] - read FIFO full.

Cleared by ``HSCI_MASTER_CLEAR_ERRORS``.
ENDFIELD

HSCI Master Link Error Info
ENDREG

FIELD
[30:0] 0x00000000
HSCI_LINK_ERR_INFO
RO-V
Captured on entry to LINK_ERR:

* [3:0] - previous state.
* [4] - signal lock.
* [5] - RX link timeout.
* [6] - TX acquire timeout.
* [7] - decision made.
* [11:8] - TX clock adjustment value.
* [15:12] - TX clock adjustment.
* [16] - TX link-up achieved.
ENDFIELD
