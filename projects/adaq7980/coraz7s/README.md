# ADAQ7980/CORAZ7S HDL Project

- VIO with which it was tested in hardware: 3.3V

## Building the project

```
cd projects/adaq7980/coraz7s
make
```

The EVAL-ADAQ7980/88-PMDZ board is connected to the Cora Z7S PMOD JA connector.
The power-down pins (PD_REF, PD_AMP, PD_LDO) are set with jumpers on the board.
